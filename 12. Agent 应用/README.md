# Agent 应用

## Fast Look

**应用链路**：`用户目标 → Agent 规划 → Skill/Plugin → 文件、浏览器、代码或知识库工具 → 记忆/定时触发 → 审计与人工确认`。本章关注可用产品能力，而非如何训练 Agent。

#### Claude Code

- **描述**：面向软件工程任务的编码 Agent，可理解仓库、修改文件、运行命令和使用扩展能力。
- **与通用聊天模型的区别**：拥有受控的工作区、工具执行和代码验证闭环，而非只生成建议文本。
- **优点**：适合多文件修改、测试与工程协作，能将需求落为可验证改动。
- **缺点/注意点**：命令、依赖安装与代码改动都可能产生副作用；需明确作用域、审阅 diff 并保护密钥。

#### Skill/Plugin 与 `ljg-skill-xray-paper`

- **Skill/Plugin 描述**：将专门知识、工具调用和固定工作流封装为可复用能力。
- **`ljg-skill-xray-paper` 描述**：面向论文阅读/解析的专用技能。
- **与自由 Prompt 的区别**：将步骤、输入输出约定和工具边界显式固化。
- **优点**：提高重复任务的一致性，降低每次重新提示的成本。
- **缺点/注意点**：第三方技能可能有过度权限、提示注入或依赖失效风险；安装前需审计来源和权限。

#### OpenClaw：长期记忆、持续运行、远程控制与定时触发

- **描述**：以长期记忆、7×24 运行、远程控制、定时任务和计算机/文件访问为核心的持续型 Agent 能力集合。
- **与单次会话 Agent 的区别**：可跨时间保存状态、自动唤醒并实际操作外部系统。
- **优点**：适合持续监控、个人助理和跨应用自动化。
- **缺点/注意点**：持久权限和无人值守执行显著扩大攻击面；必须最小权限、任务预算、显式确认、审计日志和可撤销机制。

#### `scientify` 与 Notion 笔记整理

- **`scientify` 描述**：论文阅读/撰写类插件能力；**Notion 整理**：将结果写入结构化笔记空间。
- **与本地一次性输出的区别**：把研究/写作流程接入外部知识管理与协作系统。
- **优点**：减少资料搬运，形成可检索、可复用的研究资产。
- **缺点/注意点**：外部文档写入可能误覆盖、泄露敏感材料或制造错误引用；应采用草稿区、来源链接和人工发布确认。
