# 03.训练数据集

## Fast Look

**数据链路**：`原始语料/偏好对 → Chat Template → input_ids、labels、attention_mask → 预训练/SFT/RM/PPO 不同损失`。同一文本因训练阶段不同会被组织为不同实体。

#### 预训练语料与领域继续预训练（CPT）

- **描述**：预训练使用大规模无标注文本做 next-token prediction；CPT 在通用基座上继续用领域原始文本训练。
- **与 SFT 的区别**：预训练/CPT 注入语言与领域知识，SFT 学习指令行为和回答格式。
- **优点**：无需逐条人工问答标注，适合大量领域文档。
- **缺点/注意点**：数据质量、重复、污染和版权风险会直接写入模型；CPT 可能损害通用能力，需混入通用数据或做回归评测。

#### SFT 数据：instruction、input、output 与 messages

- **描述**：SFT 将任务写为指令—输入—回答，或 system/user/assistant 多轮 messages；通常只对 assistant 输出计算 loss。
- **与预训练文本的区别**：预训练预测整段连续文本；SFT 显式标注期望响应与角色边界。
- **优点**：直接塑造指令遵循、格式和对话能力，易按业务构造。
- **缺点/注意点**：Chat Template、EOS、角色 token 和 label mask 必须与基座模型匹配；错误模板会造成训练/推理不一致。

#### Reward Model（RM）偏好对数据

- **描述**：对同一 prompt 提供 chosen 与 rejected 回答，训练模型给 chosen 更高分。
- **与 SFT 的区别**：SFT 学一个“正确答案”，RM 学两个回答的相对偏好排序。
- **优点**：能表达帮助性、安全性、文风等难以写成唯一标准答案的信号。
- **缺点/注意点**：标注者偏好和位置偏差会进入奖励模型；偏好对不等于绝对真值。

#### PPO/RLHF 轨迹数据

- **描述**：包含 prompt、策略模型生成 response、奖励/优势值、旧策略 logprob、价值估计等，用于在线或离线策略更新。
- **与 RM 数据的区别**：RM 训练静态偏好排序；PPO 需要策略采样轨迹和优化所需的过程统计量。
- **优点**：可直接针对奖励最大化并加入 KL 约束。
- **缺点/注意点**：数据分布随策略变化，缓存/复用需谨慎；奖励、reference logprob 和 mask 对齐错误会使训练失真。

#### 数据规模、质量、去重与评测集

- **描述**：数据量决定覆盖面，质量决定监督上限；去重降低记忆和过拟合，独立评测集用于选择模型与防止数据泄漏。
- **与“只增加样本数”的区别**：高质量、多样、贴近目标分布的数据通常比重复低质数据更有效。
- **优点**：形成可迭代的数据闭环，能定位模型问题是数据还是训练问题。
- **缺点/注意点**：不存在通用的“需要多少条”；评测集若混入训练或由同一生成器批量合成，结论会过于乐观。
