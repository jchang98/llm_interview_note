# 01.大语言模型基础

## Fast Look

**阅读链路**：`中文文本 → 分词/子词 → 词向量 → CNN/RNN/Transformer 表征 → 自回归语言模型 → Decoder-only LLM`。本章的传统 NLP 实体用于理解现代 LLM 的输入、表示和训练目标。

#### N-gram 语言模型

- **描述**：用前 `n-1` 个词估计当前词的条件概率，是统计语言模型的基本形式。
- **与之前方法的区别**：相对词频/规则系统，显式建模局部上下文概率。
- **优点**：可解释、训练与推理简单，是语言建模和熵概念的起点。
- **缺点/注意点**：上下文窗口固定，数据稀疏和 OOV 严重；不能替代神经网络 LLM。

#### 自回归语言模型（Causal LM）与 Prefix LM

- **Causal LM 描述**：用因果 mask 仅根据左侧 token 预测下一个 token。
- **Prefix LM 描述**：前缀内部可双向注意，生成区仍以因果方式依赖前缀与已生成内容。
- **与之前方法的区别**：二者都可生成；Prefix LM 相对纯 Causal LM 为输入前缀提供更强双向理解。
- **优点**：Causal LM 训练目标与生成过程一致、扩展简单；Prefix LM 更适合“读输入再生成”的任务。
- **缺点/注意点**：生成阶段都逐 token 串行；mask 设计决定信息可见范围，不能混淆为完全双向模型。

#### 中文分词：词典匹配、统计模型与 Jieba

- **词典匹配描述**：按词表做正向/逆向最大匹配；**优点**是快且可控，**缺点**是歧义和未登录词处理弱。
- **统计分词描述**：用 HMM、CRF 等模型为字符序列预测边界；**区别**是从规则转为数据驱动，**优点**是能泛化新词，**缺点**是依赖标注/语料质量。
- **Jieba 描述**：以前缀词典构造 DAG，动态规划求最大概率路径，并用 HMM 处理未登录词；提供自定义词典、关键词、词性和并行切分。
- **注意点**：现代 LLM 通常使用 BPE/SentencePiece 子词 tokenizer，不应把 Jieba 直接当作 LLM 的标准 tokenizer。

#### 词性标注、HMM 与 Viterbi

- **描述**：词性标注为 token 分配名词、动词等标签；HMM 用状态转移/发射概率建模，Viterbi 搜索最优标签路径。
- **与词典查找的区别**：词典法只匹配已知词条；HMM 利用上下文概率处理歧义与未登录词。
- **优点**：结构清晰、可解释，是序列标注的经典基线。
- **缺点/注意点**：马尔可夫独立假设较强；Transformer 表征模型通常在复杂上下文标注上更强。

#### 句法分析：成分句法与依存句法

- **成分句法描述**：把句子划分为短语层级树；**依存句法描述**：以词为节点、以依存关系为边。
- **与词性标注的区别**：词性回答“词是什么类别”，句法回答“词/短语之间如何组成句子”。
- **优点**：显式提供结构信息，适用于信息抽取、问答和语法分析。
- **缺点/注意点**：标注体系和领域迁移会影响效果；LLM 可隐式学习部分句法，但不天然输出可验证语法树。

#### 静态词向量、Word2Vec、CBOW 与 Skip-gram

- **描述**：词向量将词映射为稠密向量；CBOW 由上下文预测中心词，Skip-gram 由中心词预测上下文。
- **与 one-hot 的区别**：one-hot 不表达相似性且维度高；词向量可通过距离/点积表示语义相近。
- **CBOW 与 Skip-gram 的区别**：CBOW 更快、适合高频词；Skip-gram 训练较慢但稀有词表示常更好。
- **优点**：低维高效，支持相似词检索与线性类比。
- **缺点/注意点**：同一词只有一个静态向量，无法区分多义词；不能替代上下文化 token embedding。

#### Hierarchical Softmax 与 Negative Sampling

- **Hierarchical Softmax 描述**：用 Huffman 树将全词表 softmax 化为一条路径决策。
- **Negative Sampling 描述**：只对正样本和少量采样负例训练二分类目标。
- **与完整 Softmax 的区别**：都避免遍历整个词表；前者依赖树路径，后者依赖负例分布。
- **优点**：显著降低 Word2Vec 等大词表训练成本。
- **缺点/注意点**：树结构或负采样分布会影响结果；负采样目标不是完整概率归一化。

#### CNN、RNN/LSTM 与 Transformer

- **CNN 描述**：卷积捕获局部 n-gram 模式；**优点**是并行、局部特征强，**缺点**是远距离依赖需堆层。
- **RNN/LSTM 描述**：递归维护历史状态，LSTM 用门控缓解梯度消失；**优点**是天然序列顺序，**缺点**是训练串行、长依赖仍受限。
- **Transformer 描述**：自注意力直接连接任意 token；**相对 RNN** 可并行且长依赖强，**缺点**是长序列注意力成本二次增长。

#### Sigmoid、Tanh、ReLU、GeLU、Swish 与 GLU

- **Sigmoid/Tanh**：早期平滑激活；**优点**是有界，**缺点**是饱和区梯度消失。
- **ReLU**：正区线性、计算简单；**优点**是缓解梯度消失，**缺点**是负区死亡神经元。
- **GeLU/Swish**：平滑门控式激活；**相对 ReLU** 不硬截断，**优点**是大模型训练常更稳定，**缺点**是计算更复杂。
- **GLU**：用门分支选择信息；**优点**是表达力强，**缺点**是额外参数与计算；SwiGLU 将在第 02 章展开。

#### Decoder-only、Encoder-only 与 Encoder–Decoder

- **Decoder-only 描述**：因果自注意力预测下一个 token，如 GPT/Llama。
- **Encoder-only 描述**：双向编码输入，如 BERT；**Encoder–Decoder 描述**：Encoder 理解输入、Decoder 通过 cross-attention 生成输出，如 T5。
- **与前两者的区别**：Decoder-only 用一个统一续写目标覆盖多数任务；Encoder-only 更偏理解，Encoder–Decoder 更适合条件生成。
- **优点**：Decoder-only 预训练—推理一致、数据利用直接、零样本生成好。
- **缺点/注意点**：生成串行；不能据此断言 Decoder-only 在所有分类、翻译或小数据任务上总是最优。
